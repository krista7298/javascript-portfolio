# Krista Agustin - JavaScript Portfolio

## About This Portfolio

This portfolio was created to demonstrate the skills I have developed while learning JavaScript and web development. It includes examples of HTML, CSS, JavaScript, DOM manipulation, browser storage, and interactive webpage features.

## Languages and Technologies

- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitHub Pages

## Portfolio Features

The portfolio includes several JavaScript features that I have developed throughout the course. These include dynamically generated content, project objects, DOM manipulation, event handling, a welcome modal, a contact form, and a Dark Mode option.

The Projects section uses JavaScript objects stored in an array. The project data is converted to JSON and saved using sessionStorage. When the page loads, the stored information is retrieved, parsed, and dynamically displayed on the webpage.

The Dark Mode preference is saved using localStorage so the user's preference can remain after refreshing the page.

## Dependencies

This project does not require any external JavaScript libraries. It runs in a modern web browser and uses built-in browser features including localStorage and sessionStorage.

An internet connection is needed to access the GitHub repository, GitHub Pages website, and project images.

## How to Run

The portfolio can be viewed through GitHub Pages or by opening the index.html file in a web browser.
